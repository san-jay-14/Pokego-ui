# Pokémon Explorer

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Tanstack Query
- Zustand (if required for state management)

## Frontend Standards

- TypeScript over JavaScript
- Reusable components
- No unnecessary useEffect
- No giant components
- No unnecessary prop drilling
- Mobile-first responsive design
- Accessible interactive elements
- Centralized design tokens
- Centralized Pokémon type configuration
- Proper loading/error/empty states
- No unnecessary dependencies

## Design

The application should feel like a polished real-world product.

Avoid generic AI-generated UI.

Prioritize:

- typography
- spacing
- hierarchy
- responsive behavior
- interaction states
- subtle animation
- accessibility

## API

Use PokéAPI:
https://pokeapi.co/api/v2/

Keep API logic inside the service/data layer.

## Before Completing Any Feature

Check:

1. functionality
2. responsive behavior
3. loading state
4. error state
5. empty state
6. accessibility
7. component architecture
